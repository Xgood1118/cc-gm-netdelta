# 快照差量同步

一个能算出最小差量、并在丢包时按序号补齐的快照同步器

## 保留签名

- `Snapshot`
- `diff(a, b)`
- `apply(state, delta)`
- `seq_gap(seqs)`

## 差量格式

`diff(a, b)` 返回操作列表，只包含真正变化的字段，每个操作定位到一个叶子：

```json
{"op": "set", "path": ["b", "x"], "value": 2}
{"op": "del", "path": ["y"]}
```

- 嵌套字典逐层递归到叶子；新增键整体 `set`，删除键在键本身处 `del`（不展开子树），保证最小。
- 键按字典序遍历，同一对输入两次差量结果完全一致。
- `apply(state, delta)` 在深拷贝上应用，不改动原状态；应用后与直接接收全量快照完全一致。
- 无变化帧差量为空列表 `[]`；整帧删除产生若干顶层 `del`，应用后为空字典；首次同步发送全量快照。

## 丢包补齐规则

差量帧携带 `(base, seq)`。接收端（`Receiver`）仅当 **base == 当前已应用序号 且
seq == base + 1** 时才应用该差量；否则一律丢弃，并请求发送方用**最新帧的全量快照**
补齐（resync）。缺口期间的差量绝不应用到旧状态上——因为它的基准状态本地并不存在，
强行应用会得到未定义的结果。补齐后状态与不丢包完全一致。`seq_gap(seqs)` 返回已收
序号中缺失的序号列表，用于识别缺口。
